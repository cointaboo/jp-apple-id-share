### 自己注册日区号

1. 准备一个没用过的邮箱

3. 地址填一个真实的日本地址（公开的商场/酒店地址即可）

## 三、日区特有的坑

### 1. 日区账号的付款方式

日区 App Store 只接受：
- 日本发行的信用卡
- 日本 iTunes 礼品卡（可以在第三方渠道买到）

**绑定中国信用卡会失败**，这是最常见的卡点。如果只是下载免费 App，付款方式选「无」就行。

### 2. 日区应用的内购

日区应用的内购需要用日区余额（礼品卡充值）。共享号**绝对不要充值**——钱会打水漂。

### 3. 语言问题

日区 App Store 界面是日文。搜索时用日文原名更准，比如搜「マンガ」而不是「manga」。

### 4. 地区切换有冷却

Apple ID 切换国家/地区有频率限制，**一年内不能频繁切换**。如果你用自己主号切来切去，可能被限制。

**正确做法**：用一个专门的号做日区，主号不要动。

## 四、常见问题

**Q：日区共享号登录后 App Store 还是中文？**
界面语言跟设备语言走，跟账号地区无关。搜到的内容和价格按账号地区算。

**Q：怎么确认现在是日区？**
App Store → 头像 → 账户 → 国家/地区，应显示 Japan。或者看价格单位是 ¥（日元）。

**Q：日区号和美区号能同时用吗？**
一台设备同一时间只能登录一个 App Store 账号。想切换就退出再登。

**Q：下载的日区 App 更新时要重新登录吗？**
要。更新时 App Store 会要求登录当初下载它的那个账号。

**Q：共享号提示"此账号已在其他设备登录"？**
共享号就是这样，多人同时在用。能登就登，登不上换下一个。

**Q：日区共享号会不会影响我的 iCloud？**
只要不在「设置」里登录，就完全不影响。iCloud 和 App Store 是两个独立的登录入口。
